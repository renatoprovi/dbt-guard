# Security Policy

## Supported Versions

dbt-guard is pre-1.0 and moves fast. Only the latest release and `main` receive security fixes.

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, use GitHub's private vulnerability reporting: go to the
[Security tab](https://github.com/renatoprovi/dbt-guard/security) of this
repository and click **"Report a vulnerability"**. This opens a private
advisory visible only to the maintainer until a fix is ready.

You should expect an initial response within a few days. Once a fix is
available, we'll coordinate disclosure and publish a security advisory
crediting the report (unless you prefer to stay anonymous).
